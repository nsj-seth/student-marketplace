# Phase 08A — Product CRUD + Inventory

Seller UI now supports listing products per owned business, creating/editing products, changing authoritative stock quantities, activating/deactivating products, and soft removal.

Routes:
- `/seller/businesses/:businessId/products`
- `/seller/businesses/:businessId/products/new`
- `/seller/businesses/:businessId/products/:productId`

Images are intentionally deferred to Phase 08B. Public product browsing is deferred to Phase 08C.
